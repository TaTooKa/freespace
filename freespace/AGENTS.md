# Rules for agents working in this repo

- NEVER commit, push, stage, or otherwise write to git (no `git commit`, `git push`, `git add`, `git checkout` of branches, etc.). The user does all git operations personally, after thoroughly reviewing diffs. Agents may inspect git state (status, diff, log) freely.
- If an agent creates a fix, leave the changes unstaged/uncommitted for the user to review.
